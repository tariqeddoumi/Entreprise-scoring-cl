# Présentations archivées

Ces deux présentations d'octobre 2026 sont remplacées par :

- `../Notation_entreprises_synthese_management.pptx` — synthèse management (modèle, groupes, entrées en relation, renotation, statistique) ;
- `../Ancien_vers_nouveau_modele_notation.pptx` — de l'ancien modèle (cahier des charges 2007) au nouveau modèle, correspondance critère par critère, conformité BAM, circuit de validation, notes détaillées ;
- `../../modelisation/Guide_modelisation_statistique.docx` — méthode statistique détaillée.

Elles sont conservées pour la traçabilité. **Ne plus les diffuser** : elles décrivent
l'ancienne règle du moteur 3.0 (une donnée absente valait 25 sur 100, et seules trois
données étaient critiques), remplacée en moteur 3.1 par la borne basse (0) et cinq
données critiques.

`Defense_nouveau_modele_notation.pptx` (novembre 2026) est également archivée : elle
décrivait l'ancien modèle à partir de l'extraction de la base de production, et non de
sa spécification. Deux affirmations y sont inexactes : l'outil n'est pas un classeur
Excel et une base Access (la base transmise est une extraction de l'outil en
production), et l'ancien modèle comporte bien un outil TPE / PRO dédié (score
quantitatif, comportement du compte courant, signaux d'alerte). Elle est remplacée par
`../Ancien_vers_nouveau_modele_notation.pptx`, construite sur le cahier des charges
« Outil de notation Pro / TPE / PME / GE », version 2.1 du 11 mai 2007.
